# Interactive Voronoi Market Simulator 🛰️

このプロジェクトは、GIS（地理情報システム）の基本的な概念である**ボロノイ分割**を用いた、インタラクティブな商圏分析シミュレーターです。地図上での店舗配置・撤退が、周囲のナワバリ（商圏）にどのような影響を与えるかをリアルタイムに可視化します。

## 🌐 デモ
https://marumaruyama.github.io/volonoi-sample-Gemini/index.html

## ✨ 主な機能
- **リアルタイム・ボロノイ生成**: 地図をクリックするだけで、即座に境界線が再計算されます。
- **動的削除機能**: `Shift + 左クリック` で既存の店舗を削除し、商圏の再編をシミュレートできます。
- **デロネー図の重畳**: 店舗間の隣接ネットワーク（デロネー三角形）を薄く表示し、地理的な繋がりを可視化します。
- **商圏面積ランキング**: 各ボロノイ領域の面積を計算し、サイドバーにリアルタイムでランキング表示します。

## 🛠 使用技術
- **[Leaflet.js](https://leafletjs.com/)**: インタラクティブな地図表示と座標変換。
- **[D3.js (d3-delaunay)](https://github.com/d3/d3-delaunay)**: 高速なボロノイ図・デロネー図の計算。
- **OpenStreetMap**: 背景地図データ。

## 📖 使い方
1. **店舗の追加**: 地図上の任意の場所を**左クリック**すると、新しい店舗（赤ドット）が設置されます。
2. **店舗の削除**: 既存の赤いドットを **Shiftキーを押しながらクリック** すると、その店舗が撤退し、周囲の商圏が再計算されます。
3. **分析**: 右側のサイドバーで、どの店舗が最も広い商圏を持っているかを確認できます。

## 🎓 学習のポイント（大学生向け）
このツールを通じて、以下のGISの基礎概念を学ぶことができます。
- **近接性分析**: 「最も近い地点」の集合が作る境界線の数学的性質（垂直二等分線）。
- **座標系の変換**: 緯度経度（地理座標）からピクセル（スクリーン座標）への投影。
- **エリアマーケティング**: 実際のチェーン店配置を模倣することで、新規出店や撤退が競合他社に与える影響の理解。
