# Interactive Voronoi Market Simulator

このプロジェクトは、GIS（地理情報システム）の基本的な概念である**ボロノイ分割**を用いた、インタラクティブな商圏分析シミュレーターです。地図上での店舗配置・撤退が、周囲のナワバリ（商圏）にどのような影響を与えるかをリアルタイムに可視化します。

## デモ
https://marumaruyama.github.io/volonoi-sample-Gemini/index.html

## 主な機能

### 背景地図
| スタイル | 内容 |
|---|---|
| OSM（カラー） | OpenStreetMap（デフォルト） |
| OSM（グレースケール） | CSSフィルターによる白黒表示 |
| Google ロードマップ | Google Maps 道路地図 |
| Google ロードマップ（グレー） | Google Maps グレースケールスタイル |
| Google 衛星画像 | Google Maps 航空写真 |

Google Maps の表示には Google Maps API キーが必要です（後述）。

### ボロノイ面の色分けモード
| モード | 色スケール | 内容 |
|---|---|---|
| なし | — | 薄い赤で均一表示 |
| 面積比 | 淡黄 → 濃赤 | 面積に応じたグラデーション |
| 最大傾斜度（国土地理院DEM） | 淡橙 → 濃橙 | 各面内の**最大**傾斜角によるグラデーション |
| 平均傾斜度（国土地理院DEM） | 淡橙 → 濃橙 | 各面内の**平均**傾斜角によるグラデーション |
| 最大−平均傾斜度（国土地理院DEM） | 淡橙 → 濃橙 | 最大傾斜角と平均傾斜角の**差**によるグラデーション |

- **透過度スライダー**: ボロノイ面の不透明度を 5〜90% で調整可能
- **カラー凡例**: 色分けモード選択時に最小・最大値付きで凡例を表示

### 傾斜度の算出方法（国土地理院 DEMタイル使用）

#### 1. サンプル点の配置

各ボロノイ面の外接矩形内に **8 × 8 = 64点** のグリッドを配置し、
レイキャスト法で面の内側にある点のみを使用します。

```
    ボロノイ面のサンプル点イメージ（8×8グリッド）

    ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
    │ ·   ·   ·   ·   ·   ·   ·   · │
    │ ·   ●   ●   ●   ●   ●   ·   · │
    │ ·   ●   ●   ●   ●   ●   ●   · │   ● 面の内側（標高取得）
    │ ·   ●   ●   ●   ●   ●   ●   · │   · 面の外側（スキップ）
    │ ·   ·   ●   ●   ●   ●   ●   · │
    │ ·   ·   ·   ●   ●   ●   ·   · │
    │ ·   ·   ·   ·   ·   ·   ·   · │
    └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘
```

標高データは国土地理院の DEMタイルから取得します（ズームレベル 14）。

```
優先順位：dem5a（5mレーザー測量）→ dem5b（5m写真測量）→ dem（10mメッシュ）
URL例: https://cyberjapandata.gsi.go.jp/xyz/dem5a/14/{x}/{y}.txt
```

#### 2. 傾斜角の計算

隣接するサンプル点ペア（右方向・下方向）それぞれについて、
標高差と水平距離から傾斜角を求めます。

```
                         ↑ 標高 (m)
          点B (hB)      │
            ○           │  Δh = |hB − hA|
           /│           │
          / │Δh         │
         /  │           │
        ○───┘           └──────────────────→ 水平距離 (m)
       点A  d
      (hA)

      傾斜角 θ = arctan( Δh / d )  [度]

      ※ d はハバーサイン公式による球面距離
```

#### 3. 最大傾斜度 vs 平均傾斜度

同一のサンプルグリッドから、2つの指標を **1回の標高取得で同時に** 算出します。

```
  全隣接ペアの傾斜角リスト:  [θ₁, θ₂, θ₃, … θₙ]

  ┌─────────────────────────────────────────────────────┐
  │  最大傾斜度 = max(θ₁, θ₂, … θₙ)                   │
  │              → 面内で最も急な場所を代表              │
  │              → 崖・急斜面の検出に有効               │
  ├─────────────────────────────────────────────────────┤
  │  平均傾斜度 = (θ₁ + θ₂ + … + θₙ) / n             │
  │              → 面全体の起伏の緩急を代表             │
  │              → 土地利用・開発適性の評価に有効       │
  └─────────────────────────────────────────────────────┘
```

#### 使い分けの目安

| 指標 | 向いているケース |
|---|---|
| 最大傾斜度 | 急斜面・崖の有無を確認したい／最悪ケースを把握したい |
| 平均傾斜度 | 面全体の地形的な難易度を比較したい／農地・宅地適性を見たい |
| 最大−平均傾斜度 | 地形の**ばらつき**（谷戸・急崖の局所性）を検出したい／最大値だけでは見えない地形の不均一さを評価したい |

#### 最大−平均傾斜度の見方

差が**大きい**面 → 一部に急崖・急斜面が局所的に存在（谷戸地形や崖地など）  
差が**小さい**面 → 面内の傾斜が均一（一様な斜面や平坦地）

```
  差が大きい（谷戸型）         差が小さい（均一斜面型）

  急│    ╱╲                  急│
    │   ╱  ╲                   │  ╱╱╱╱╱
    │  ╱    ╲                  │ ╱╱╱╱╱╱
  緩│──        ──            緩│╱╱╱╱╱╱╱
    └──────────→               └──────────→
    θmax: 高, θavg: 低          θmax: 中, θavg: 中
    差: 大 → 濃橙              差: 小 → 淡橙
```

> **注意**: サンプル点数（8×8）は処理速度との兼ね合いで設定されており、  
> 面が非常に小さい場合や地形が複雑な場合は精度に限界があります。  
> 詳細な解析には国土地理院提供の GIS データを直接ご利用ください。

### 基本操作
- **左クリック**: 店舗（赤ドット）を追加
- **Shift + 左クリック**: 店舗を削除
- **JSONインポート**: `{ lat, lng, id, name }` 形式の JSON ファイルから店舗データを読み込み

## セットアップ

### Google Maps API キーの設定
Google Maps を使用するには、Google Cloud Console で Maps JavaScript API を有効にした API キーが必要です。

1. リポジトリの **Settings → Secrets and variables → Actions** を開く
2. `MAPS_API_KEY` という名前でシークレットを作成し、APIキーを設定する
3. `main` ブランチまたは `claude/voronoi-google-maps-rWqgR` ブランチにプッシュすると GitHub Actions が自動的にキーを埋め込んでデプロイします

### デプロイ（GitHub Pages）
```yaml
# .github/workflows/deploy.yml がトリガーするブランチ
branches:
  - main
  - claude/voronoi-google-maps-rWqgR
```
プッシュ時に GitHub Actions が `index.html` 内のプレースホルダー `__GOOGLE_MAPS_API_KEY__` を `MAPS_API_KEY` シークレットで置換した上で、GitHub Pages へ自動デプロイします。

## サンプルデータ

### 東京都内 公立小学校（`data/tokyo_elementary_schools.json`）

東京23区の公立小学校75校の位置データをサンプルとして収録しています。  
各区から2〜4校を選び、区全体をカバーするよう分布させています。

コントロールパネルの **Import JSON** からこのファイルを読み込むと、  
23区全域にわたるボロノイ図（学校通学圏の近似）が描画されます。  
地図をズームレベル 11〜12 程度まで縮小すると全体が見やすくなります。

> **注記**: 座標は公開情報をもとに作成した近似値です。  
> 正確な位置は国土交通省 [国土数値情報 学校データ (P29)](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P29.html) をご参照ください（CC BY 4.0）。
